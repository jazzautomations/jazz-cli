# Código de Conduta / Code of Conduct

Este projeto adota o [Contributor Covenant, versão 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
([em português](https://www.contributor-covenant.org/pt-br/version/2/1/code_of_conduct/)).
This project follows the Contributor Covenant 2.1; the summary below does not replace it.

## Nosso compromisso

Queremos que participar do projeto seja uma experiência livre de assédio para todas as pessoas,
independentemente de idade, corpo, deficiência, etnia, identidade ou expressão de gênero, nível de
experiência, educação, situação socioeconômica, nacionalidade, aparência, raça, religião ou
orientação sexual.

## O que esperamos

- Empatia e gentileza; respeito a opiniões e experiências diferentes.
- Crítica construtiva, dada e recebida com elegância; assumir responsabilidade pelos próprios erros.
- Foco no que é melhor para a comunidade.

## O que não aceitamos

- Linguagem ou imagens sexualizadas, assédio público ou privado, insultos e ataques pessoais.
- Publicar dados privados de alguém sem permissão explícita.
- Qualquer conduta inadequada num ambiente profissional.

## Aplicação

Relate condutas inaceitáveis às pessoas mantenedoras pelo e-mail indicado no perfil da organização
**jazzautomations** no GitHub. Toda denúncia é analisada com sigilo. As consequências seguem as
diretrizes de aplicação do Contributor Covenant 2.1: correção, advertência, banimento temporário ou
banimento permanente.
