Um agente de código no terminal que roda em qualquer máquina — até num Pentium M de 2005. A coding agent for the terminal that runs on any machine — even a 2005 Pentium M.

O jazz é um binário estático só, escrito em Go, sem Node e sem dependências. Lê, roda, edita e confere o que fez, com o modelo que você escolher, inclusive os grátis. Se o modelo é fraco, o harness cobra o que um prompt só pediria. jazz is a single static binary written in Go, with no Node and no dependencies. It reads, runs, edits and checks what it did, with the model you choose, free ones included. When the model is weak, the harness enforces what a prompt could only ask for.

01 · a históriathe story

Não existia um agente de código para este notebook. Então ele foi feito.There was no coding agent for this laptop. So one was built.

Tudo começou com um Dell Latitude D610: Pentium M de 32 bits, 2 GB de RAM, antiX Linux. Claude Code, Codex, opencode e os outros agentes de terminal pedem 64 bits ou um runtime Node moderno. Nenhum rodava ali.

It started with a Dell Latitude D610: a 32-bit Pentium M, 2 GB of RAM, antiX Linux. Claude Code, Codex, opencode and the other terminal agents need 64 bits or a modern Node runtime. None of them ran there.

A resposta foi escrever um em Go, compilado de forma cruzada para linux/386: um binário estático, uma interface leve que não pisca por SSH, poucas ferramentas e um prompt pequeno que cabe no contexto curto de um modelo grátis.

The answer was to write one in Go, cross-compiled for linux/386: a static binary, a light interface that doesn't flicker over SSH, a few tools and a small prompt that fits in a free model's short context.

Quem dirige o projeto é a Jazz Automations. O código foi escrito por agentes de IA sob direção humana: decidir o que estudar, o que medir, o que cortar e o que não publicar sem prova. O nome vem daí, e as palavras do spinner também (Improvisando, Afinando, Swingando).

The project is run by Jazz Automations. The code was written by AI agents under human direction: deciding what to study, what to measure, what to cut and what not to publish without proof. That's where the name comes from, and the spinner words too (Improvisando, Afinando, Swingando — improvising, tuning, swinging).

02 · o que ele fazwhat it does

Pequeno por fora, exigente por dentro.Small on the outside, demanding on the inside.

O conjunto de ferramentas é pequeno de propósito. O que cresce é o harness: tudo que cerca o modelo e cobra resultado.The tool set is small on purpose. What grows is the harness: everything around the model that demands results.

“Pronto” honestoHonest “done”

Modelo fraco gosta de dizer que fez. O jazz confere: testes que já existiam ficam protegidos, enfraquecer teste não vale, resposta hardcoded é detectada, e um turno que editou código não termina antes de os testes rodarem depois da última edição. Se o modelo diz que fez sem ter chamado ferramenta nenhuma, a resposta sai marcada.

Weak models like to say they did it. jazz checks: existing tests are protected, weakening a test doesn't count, hardcoded answers are detected, and a turn that edited code can't end before the tests ran after the last edit. If the model claims it did something without calling any tool, the answer is flagged.

    Without a network, deterministic shortcuts keep working: 19 built-in scripts (tests, git, logs, stack traces, JSON) answer with no model at all.

  • Omni e juizOmni and judge

    Roteia entre provedores grátis (pago só em emergência), com fallback quando um cai. O juiz escolhe por tipo de tarefa com um placar UCB1 medido na sua máquina.

    Routes across free providers (paid only as an emergency), with fallback when one goes down. The judge picks per task type with a UCB1 scoreboard measured on your machine.

  • ParaleloParallel

    Leituras em paralelo e subagentes task com contexto próprio, cada um com sua sessão ligada ao pai.

    Parallel reads and task subagents with their own context, each with a session linked to its parent.

  • Sandbox

    Em macOS e Linux compatíveis, o sandbox do sistema isola processos. Windows usa limites de processo próprios. No Termux/Android não há sandbox do sistema: turbo fica indisponível e volta para auto; proot não é uma fronteira de segurança.

    On supported macOS and Linux systems, the OS sandbox isolates processes. Windows uses its own process limits. Termux/Android has no OS sandbox: turbo is unavailable and falls back to auto; proot is not a security boundary.

  • Termux no AndroidTermux on Android

    Instala o binário nativo Android/arm64 sem root no prefixo do Termux. Prefira ask ou plan; yolo sem sandbox exige consentimento explícito. O Android não fornece o sandbox do sistema do jazz; turbo não fica disponível e proot não muda isso.

    Installs the native Android/arm64 binary without root into the Termux prefix. Prefer ask or plan; yolo without a sandbox requires explicit consent. Android does not provide jazz's OS sandbox; turbo is unavailable, and proot does not change that.

  • Atalhos e filaShortcuts and queue

    / opens the command palette, Ctrl+R searches history, and @ picks files. Type while the agent works to queue instructions for now or later.

  • Documentação por versãoVersioned documentation

    The docs tool reads local and cached documentation offline. Context7 is opt-in: it queries the web only when enabled, through guarded HTTP, for relevant snippets.

  • Revisão e privacidadeReview and privacy

    --review pede a um subagente só-leitura para revisar o diff; a análise é heurística, não prova. Antes de cada pedido ao provedor, segredos reconhecidos viram marcadores <secreto:tipo#n> e o valor real fica só na sua máquina; a detecção cobre formatos conhecidos e não garante reconhecer todo segredo.

    --review asks a read-only subagent to review the diff; analysis is heuristic, not proof. Before each provider request, recognized secrets become <secreto:tipo#n> placeholders and the real value stays on your machine; detection covers known formats and cannot guarantee every secret is recognized.

    Sem WSL: Git Bash ou PowerShell, job objects. Windows nativo (PowerShell), build e CI.

    No WSL: Git Bash or PowerShell, job objects. Native Windows (PowerShell), build and CI.

03 · segurança de fábricasecurity out of the box

Camadas, não promessas.Layers, not promises.

As guardas são heurísticas que deixam ataques comuns mais visíveis. O sandbox do sistema é a fronteira de isolamento quando disponível; no Termux/Android ele não existe.The guards are heuristics that make common attacks more visible. The OS sandbox is the isolation boundary where available; it is not available on Termux/Android.

  1. L0

    SanitizaçãoSanitization sanitize.go

    Caracteres invisíveis, controles bidi, tags Unicode, homóglifos e HTML oculto saem antes de chegar ao modelo.

    Invisible characters, bidi controls, Unicode tags, homoglyphs and hidden HTML are stripped before reaching the model.

  2. L1

    Portão de confiançaTrust gate trust.go

    AGENTS.md, skills, hooks, .mcp.json e os arquivos que eles rodam ficam desligados até você confiar, por hash.

    AGENTS.md, skills, hooks, .mcp.json and the files they run stay off until you trust them, by hash.

    medido: cenário 12 fechado antes de agir, 0 ferramentasmeasured: scenario 12 closed before acting, 0 tools

  3. L2

    Guardrails guardrails.go · safety.go

    Detector de injeção (base64, hex, ROT13, URL, leet), comando perigoso, segredos. Supply chain: pacote inexistente, com menos de 30 dias, typosquat de ~1.700 nomes populares ou marcado no OSV.dev pede confirmação.

    Injection detector (base64, hex, ROT13, URL, leet), dangerous commands, secrets. Supply chain: a package that doesn't exist, is under 30 days old, typosquats one of ~1,700 popular names or is flagged on OSV.dev asks for confirmation.

  4. L3

    Portão de egressEgress gate

    Envio de dados para fora passa por um portão próprio e fica na auditoria.

    Detected transfers go through a dedicated gate and are audited. Sensitive files require fresh consent even in yolo; detection is heuristic.

  5. L4

    Cerca da pastaProject fence fence.go

    Caminhos externos exigem aprovação. Acesso direto detectado ao estado privado do Jazz é bloqueado, inclusive em yolo. A análise de shell é heurística; isolamento exige sandbox.

    External paths require approval. Detected direct access to Jazz private state is blocked, including in yolo. Shell analysis is heuristic; isolation requires a sandbox.

    Every block explains itself in one line. 3 blocks on the same target or 6 in a turn end the turn with a report.

05 · arquiteturaarchitecture

O laço nunca chama uma ferramenta direto.The loop never calls a tool directly.

Toda chamada passa pela pilha de guardas antes de chegar à ferramenta. Onde o sandbox do sistema está disponível, processos são isolados na criação; no Termux/Android, não há essa fronteira.Every call goes through the guard stack before reaching a tool. Where the OS sandbox is available, processes are isolated at creation; Termux/Android has no such boundary.
