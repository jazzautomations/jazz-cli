Um agente de código no terminal que roda em qualquer máquina — até num Pentium M de 2005. A coding agent for the terminal that runs on any machine — even a 2005 Pentium M.

O jazz é um binário estático só, escrito em Go, sem Node e sem dependências. Lê, roda, edita e confere o que fez, com o modelo que você escolher, inclusive os grátis. Se o modelo é fraco, o harness cobra o que um prompt só pediria. jazz is a single static binary written in Go, with no Node and no dependencies. It reads, runs, edits and checks what it did, with the model you choose, free ones included. When the model is weak, the harness enforces what a prompt could only ask for.

01 · a históriathe story

Não existia um agente de código para este notebook. Então ele foi feito.There was no coding agent for this laptop. So one was built.

Tudo começou com um Dell Latitude D610: Pentium M de 32 bits, 2 GB de RAM, antiX Linux. Claude Code, Codex, opencode e os outros agentes de terminal pedem 64 bits ou um runtime Node moderno. Nenhum rodava ali.

It started with a Dell Latitude D610: a 32-bit Pentium M, 2 GB of RAM, antiX Linux. Claude Code, Codex, opencode and the other terminal agents need 64 bits or a modern Node runtime. None of them ran there.

A resposta foi escrever um em Go, compilado de forma cruzada para linux/386: um binário estático, uma interface leve que não pisca por SSH, poucas ferramentas e um prompt pequeno que cabe no contexto curto de um modelo grátis.

The answer was to write one in Go, cross-compiled for linux/386: a static binary, a light interface that doesn't flicker over SSH, a few tools and a small prompt that fits in a free model's short context.

Quem dirige o projeto é a Jazz Automations. O código foi escrito por agentes de IA sob direção humana: decidir o que estudar, o que medir, o que cortar e o que não publicar sem prova. O nome vem daí, e as palavras do spinner também (Improvisando, Afinando, Swingando).

The project is run by Jazz Automations. The code was written by AI agents under human direction: deciding what to study, what to measure, what to cut and what not to publish without proof. That's where the name comes from, and the spinner words too (Improvisando, Afinando, Swingando — improvising, tuning, swinging).

02 · o que ele fazwhat it does

Pequeno por fora, exigente por dentro.Small on the outside, demanding on the inside.

O conjunto de ferramentas é pequeno de propósito. O que cresce é o harness: tudo que cerca o modelo e cobra resultado.The tool set is small on purpose. What grows is the harness: everything around the model that demands results.

“Pronto” honestoHonest “done”

Modelo fraco gosta de dizer que fez. O jazz confere: testes que já existiam ficam protegidos, enfraquecer teste não vale, resposta hardcoded é detectada, e um turno que editou código não termina antes de os testes rodarem depois da última edição. Se o modelo diz que fez sem ter chamado ferramenta nenhuma, a resposta sai marcada.

Weak models like to say they did it. jazz checks: existing tests are protected, weakening a test doesn't count, hardcoded answers are detected, and a turn that edited code can't end before the tests ran after the last edit. If the model claims it did something without calling any tool, the answer is flagged.

  • Cérebro offlineOffline brain

    Sem modelo (ou no -p, em pedidos claros só de leitura), um interpretador clássico — gramática determinística + fallback estatístico pequeno, a mesma forma que validou o NLU embarcado — roda métodos com pré-condições e verificadores. "Feito" só com evidência; sem verificador, o estado é "não verificado". E aprende sem modelo em runtime: correções viram exemplos por jazz forge, promovidos só depois de um gate held-out. Veja jazz env e jazz eval offline.

    Without a model (or in -p, for clear read-only requests), a classical interpreter — deterministic grammar plus a small statistical fallback, the same shape that proved embedded NLU — runs methods with preconditions and verifiers. "Done" only with evidence; with no verifier, the state is "unverified". And it learns with no runtime model: corrections become examples via jazz forge, promoted only after a held-out gate. See jazz env and jazz eval offline.

Camadas, não promessas.Layers, not promises.

As guardas são heurísticas que deixam ataques comuns mais visíveis. O sandbox do sistema é a fronteira de isolamento quando disponível; no Termux/Android ele não existe.The guards are heuristics that make common attacks more visible. Dangerous commands, secrets. Supply chain: a package that doesn't exist, is under 30 days old, typosquats one of ~1,700 popular names or is flagged on OSV.dev asks for confirmation.
