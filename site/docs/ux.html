    A experiência interativa do jazz (0.8.0)#

    Passo a passo do que aparece na tela quando você roda jazz numa pasta, com os textos exatos. As telas abaixo foram capturadas de uma sessão real num PTY de 86x27 (o terminal do Dell), com um modelo falso (fake/m1) e o sandbox ativo; só o caminho da pasta foi trocado por ~/projetos/app. Cores e negrito não aparecem aqui.

    Sumário: início · modos · caixa de entrada · paleta · @arquivo · perguntas · trabalho e fila · sessões · atalhos · configuração

    1. Início#

    Pasta nova#

    Na primeira vez numa pasta, antes de qualquer coisa do projeto carregar, aparece o menu de confiança. Pasta sem configuração própria recebe a versão curta:

    ╭─ pasta nova ──────────────────────────────────────────────────────────────────────╮
│ ~/projetos/app                                                                    │
│                                                                                   │
│ Confiando, a sessão roda no modo turbo. Sem confiar, no modo ask (pergunta antes… │
│                                                                                   │
│ Primeira vez nesta pasta. Confiar?                                                │
│ ▸ 1. Sim, confiar nesta pasta  lembrado nas próximas vezes                        │
│   2. Só nesta sessão                                                              │
│   3. Não, modo ask  pergunta antes de cada mudança                                │
╰───────────────────────────────────────────────────────────────────────────────────╯
  ↑↓ escolhe · enter confirma · esc não
    • Enter (ou s/y/1): ● pasta confiável: ~/projetos/app, lembrado nas próximas vezes.
    • 2 (ou o): ● pasta confiável só nesta sessão: ~/projetos/app.
    • 3, n ou Esc: ● pasta não confiada: modo ask nesta sessão (/trust confia).

    Pasta que traz configuração (AGENTS.md, .mcp.json, hooks, scripts, steering) recebe a caixa ─ confiança ─ com o título Confiar nesta pasta e ativar a configuração dela?, a frase Este projeto traz configuração que roda comandos, libera ferramentas ou dá instruções ao modelo:, a lista do que vai carregar e Só confie se você conhece este repositório.; v mostra a lista inteira. Com "trust_default": "always" a pasta sem configuração é confiada sem perguntar.

    Teclas nos primeiros 250 ms depois que o menu abre são ignoradas (uma tecla que já vinha no buffer não responde por você).

    Boas-vindas#

    ╭───────────────────────────────────────────────────────────────────────────────────╮
│ ✻ jazz  v0.8.0 · agente de código no terminal                                     │
│                                                                                   │
│   modelo  fake/m1                                                                 │
│   pasta   ~/projetos/app                                                          │
│   modo    » turbo                                                                 │
│            sandbox ativo: roda sem perguntar o que fica no projeto; pergunta fora │
│            dele, rede nova, segredos, git destrutivo e pacote suspeito            │
│                                                                                   │
│   /help ajuda  ·  esc interrompe  ·  @ menciona arquivo                           │
│   ! roda no shell  ·  shift+tab troca o modo  ·  ? atalhos                        │
╰───────────────────────────────────────────────────────────────────────────────────╯

╭───────────────────────────────────────────────────────────────────────────────────╮
│ ›                                                                                 │
╰───────────────────────────────────────────────────────────────────────────────────╯
  » turbo · fake/m1 · ? atalhos

    A linha embaixo de modo explica o modo de início uma vez por modo (a config guarda mode_intro); nas próximas vezes ela some. Os textos, por modo:

    ModoExplicação na primeira vez
    turbo (com sandbox)sandbox ativo: roda sem perguntar o que fica no projeto; pergunta fora dele, rede nova, segredos, git destrutivo e pacote suspeito
    turbo (sem sandbox)modo turbo sem sandbox do sistema (sandbox-exec/bwrap): usando as regras do auto (pergunta em comando perigoso, saída de dados e fora do projeto)
    auto (com sandbox)pergunta antes de comando perigoso, rede nova e fora do projeto · /mode turbo pergunta menos (sandbox ativo)
    auto (sem sandbox)pergunta antes de comando perigoso, rede nova e fora do projeto (sem sandbox do sistema: turbo indisponível)
    askpergunta antes de cada mudança (arquivo, comando, rede)
    plansó investiga e planeja; nada muda até você aprovar o plano
    smartum modelo rápido decide o que precisa de confirmação
    yolonão pergunta nada: use só em pasta descartável

    Depois de visto, se você está em auto com sandbox disponível, a linha do modo mostra · recomendado: /mode turbo (sandbox ativo, só pergunta o necessário).

    Abaixo de 40 colunas a caixa vira uma linha: ✻ jazz fake/m1 · ~/projetos/app. Com --banner ou terminal de 100+ colunas aparece o logo grande.

    Com jazz -c ou jazz -r <id> a ordem é: menu de confiança (se for o caso), boas-vindas, conversa retomada, aviso · sessão <id> retomada (N mensagens): <título>. Com jazz -r sem id, a lista de sessões abre logo abaixo das boas-vindas.

    2. Modos#

    O padrão, sem mode na config: turbo quando o sandbox do sistema isola (sandbox-exec no macOS, bwrap no Linux), senão auto. jazz -p é sempre auto. Um "mode" na config vence o padrão (configs antigas que gravaram "mode": "auto" ficam em auto até você apagar a linha ou usar /mode turbo). Pasta não confiada roda em ask.

    O modo aparece no rodapé, sempre:

    RodapéModo
    » turbo · fake/m1 · ? atalhosturbo
    ▸▸ auto · fake/m1 · ? atalhosauto
    ‖ plano · fake/m1 · ? atalhosplan
    ▸ ask · fake/m1 · ? atalhosask

    Shift+Tab (ou Ctrl+T) troca só nesta sessão, no ciclo turbo → auto → plan → ask → turbo. Sem sandbox o turbo sai do ciclo (seria igual ao auto). smart e yolo só com /mode smart, /mode yolo (ou --smart, --yolo). /mode <modo> troca e grava na config.

    Depois do contexto usado, o rodapé ganha ctx N% (» turbo · fake/m1 · ctx 1% · ? atalhos). Em terminal estreito ele encolhe: some primeiro o MCP, depois o contexto, o provedor e o modelo; o modo e ? atalhos ficam.

    No fim do modo plan aparece um menu:

    Executar o plano?
▸ 1. Sim, executar (modo turbo)
  2. Sim, perguntando antes de cada mudança (modo ask)
  3. Não, continuar planejando

    e, ao escolher, · modo turbo: executando o plano.

    3. Caixa de entrada#

    A caixa cresce com o texto. Enter envia; Shift+Enter, Alt+Enter ou \+Enter quebram linha (em roxterm/VTE o Shift+Enter costuma chegar como Enter comum: use \+Enter ou Alt+Enter). Colar texto de várias linhas mantém tudo como está, inclusive indentação e tabs.

    ? com a linha vazia mostra os atalhos embaixo da caixa (em duas colunas quando cabem); ? de novo esconde:

      ! roda no shell                     @ menciona arquivo
  / comandos                          esc limpa · 2× interrompe
  ↑ ↓ histórico (filtra pelo início)  ctrl+r busca no histórico
  shift+enter quebra linha (\ enter)  shift+tab troca o modo
  ctrl+o expande/recolhe a saída      ctrl+g abre no editor
  ctrl+u ctrl+k apaga até início/fim  alt+← → pula palavra
  ctrl+c 2× sai

    Histórico: ↑↓ mostram só as entradas que começam pelo que já está digitado (com a linha vazia, todas). Num texto de várias linhas, ↑↓ andam entre as linhas antes de ir ao histórico. Ctrl+R abre a busca no lugar da caixa:

    (busca) '': oi tudo bem  ctrl+r anterior · enter usa · esc cancela

    Digitar refina; Ctrl+R de novo vai para o resultado anterior; sem resultado aparece nada encontrado; Enter põe o resultado na caixa (não envia); Esc cancela.

    !comando roda direto no shell, sem passar pelo modelo.

    4. Paleta de comandos#

    / abre a paleta logo embaixo da caixa:

    ╭───────────────────────────────────────────────────────────────────────────────────╮
│ › /                                                                               │
╰───────────────────────────────────────────────────────────────────────────────────╯
  ▸ /help         esta ajuda
    /model        mostra ou troca o modelo: /model anthropic/claude-sonnet-5-5
    /models       lista modelos de um provedor: /models openrouter
    /omni         roteamento entre provedores: /omni [on|off|strategy free-first|wei…
    /key          salva uma chave de API (escondida): /key openrouter
    /login        login com a conta do ChatGPT (--browser pra fluxo no navegador)
    … +35   ↑↓ escolhe · enter usa · tab completa · esc fecha

    Digitar filtra com busca aproximada, e o nome exato vem primeiro:

    │ › /cmp                                                                            │
╰───────────────────────────────────────────────────────────────────────────────────╯
  ▸ /compact  compacta o contexto agora (opcional: foco do resumo)
    ↑↓ escolhe · enter usa · tab completa · esc fecha

    /modle + Enter roda /model; /mode + Enter roda /mode (não /model). ↑↓ movem a seleção, Tab completa na caixa com um espaço no fim (› /models), Enter roda, Esc fecha a paleta (outro Esc limpa a linha). Comandos próprios (.md em ~/.config/jazz-cli/commands, .jazz/commands, .claude/commands) entram na mesma lista.

    5. @arquivo#

    @ abre a lista de arquivos e pastas do projeto, com busca aproximada sobre o índice de nomes:

    │ › olha @ser                                                                       │
╰───────────────────────────────────────────────────────────────────────────────────╯
  ▸ cmd/server/server.go
    cmd/server/
    ↑↓ escolhe · enter usa · tab completa · esc fecha

    Enter ou Tab inserem @cmd/server/server.go na caixa. Escolher uma pasta mantém a lista aberta dentro dela. O arquivo mencionado vai junto com a mensagem.

    6. Perguntas#

    Toda pergunta é um menu numa caixa. ↑↓ (ou j/k) e Enter escolhem, o número escolhe direto e cada menu tem atalhos de uma tecla. Enter é sempre a opção destacada. Nunca é preciso digitar sim.

    Permissão#

    › rode perigoso

╭─ Bash ────────────────────────────────────────────────────────────────────────────╮
│ git branch -D jazz-pty-nada                                                       │
│                                                                                   │
│ ⚠ apaga branch do git                                                             │
│                                                                                   │
│ Rodar este comando?                                                               │
│ ▸ 1. Sim                                                                          │
│   2. Sim, e não perguntar de novo neste projeto para git: git branch -D jazz-pty… │
│   3. Não, e me diga o que fazer                                                   │
╰───────────────────────────────────────────────────────────────────────────────────╯
  ↑↓ enter · s sim · a sempre · n/esc não · e instruir · v ver tudo
    • A caixa mostra o comando exato (ou o diff da edição) e o motivo de risco inteiro em vermelho, uma linha por problema; nunca é cortado. v imprime o comando, o diff e o motivo inteiros acima do menu, que continua aberto.
    • s/y/1 sim · a/t/2 sempre · n/Esc não · e/3 não e escrever uma instrução para o agente.
    • Tecla nos primeiros 250 ms, ou enquanto você ainda está digitando (sem uma pausa de 600 ms), não responde. Isso não muda o que Enter quer dizer.
    • Depois da resposta a caixa some e fica uma linha: ● sim · Bash git branch -D … ou ● não · Bash git branch -D jazz-pty-nada, e o resultado da ferramenta mostra ⎿ negado.

    O que a opção 2 lembra (always_scope: auto): edição/escrita vale nesta sessão (nesta sessão para Edit(<pasta>/**)); comando, domínio, ferramenta MCP e script viram regra do projeto em .jazz/settings.json (neste projeto para Bash(npm test:*)); um motivo de risco vai para .jazz/approvals.json (neste projeto para <classe>: <alvo>). Ler segredo, comando catastrófico, regra ask, hook e injeção suspeita perguntam sempre.

    ask_user#

    ● Pergunta(Qual banco usar?)

╭─ pergunta ────────────────────────────────────────────────────────────────────────╮
│ Qual banco usar?                                                                  │
│ ▸ 1. SQLite  arquivo local                                                        │
│   2. Postgres                                                                     │
│   3. Outra resposta (escrever)                                                    │
╰───────────────────────────────────────────────────────────────────────────────────╯
  ↑↓ enter escolhe · ou comece a digitar a resposta · esc pula

    Depois: ● Qual banco usar? SQLite e ⎿ resposta: SQLite.

    Outras#

    Usam o mesmo menu: jobs em segundo plano ao sair (N job(s) em segundo plano rodando. Encerrar? com Sim, encerrar e sair / Não, sair e deixar rodando) e no /clear (Sim, encerrar / Não, deixar rodando); /forget (Apagar do disco a sessão <id>?, Sim, apagar / Não); o atalho determinístico ⚡ atalho; /rewind; e, fora da sessão, jazz trust, jazz worktree merge e jazz improve (sem terminal, eles caem para uma pergunta em linha). Um menu cancelado com Esc deixa ● cancelado.

    7. Enquanto o agente trabalha#

    A resposta aparece com ● e markdown quebrado na largura; cada ferramenta como ● Bash(go test ./...) com o resultado em ⎿ (até 3 linhas). No fim do turno, uma linha de totais: ✻ 1.1s · 1 ferramenta · ctx 1%.

    Você continua digitando durante o trabalho. Enter não interrompe: a mensagem entra na fila, mostrada embaixo da linha de status (na fila (2): …, um item por linha, com a dica ↑↓ editar · del remove · tab agora/depois · esc esc limpa). Mensagem curta (até 200 caracteres, ou começando com !, ei, opa, na verdade, espera) entra agora, na próxima fronteira de ferramenta; mensagem longa (ou começando com depois: ou +) vira o próximo turno. Se uma pergunta abre enquanto você digitava, o texto aparece acima da caixa (↳ na fila: …) e volta para a caixa de entrada depois.

    Esc: com texto digitado, o primeiro Esc limpa esse texto e o segundo interrompe; sem texto, um Esc já interrompe (interrompendo…). Ctrl+C interrompe sempre. Turno interrompido devolve a fila para a caixa.

    Ctrl+O expande a saída inteira da última ferramenta; Ctrl+O de novo recolhe, se a saída expandida ainda é a última coisa na tela (senão expande de novo). /expand só expande.

    8. Sessões#

    /resume, /sessions e jazz -r sem id abrem a lista no lugar, mais nova primeiro:

    › /resume
  sessões em ~/projetos/app
  ▸ 1 Tudo bem  agora  atual
        turbo · 2 msgs · concluída · ~/projetos/app
    2 Rode perigoso  agora
        turbo · 8 msgs · concluída · ~/projetos/app
  1/2  ↑↓ jk move · enter abre · esc cancela · digite filtra · tab: todas as pastas
    • Cada linha: título, data relativa (agora, há 5 min, há 2 h, ontem, há 3 dias, 12 out), atual na sessão em uso; embaixo modo · mensagens · tokens · custo · situação (concluída, incompleta, negada) · pasta.
    • ↑↓, j/k, PgUp/PgDn movem; Enter abre; 1–9 abre direto; digitar filtra (tolerante a erro de digitação; / começa um filtro para procurar j, k ou dígitos); Esc limpa o filtro, e com o filtro vazio cancela; Tab mostra todas as pastas, agrupadas. Sessão de outra pasta não é carregada: essa sessão é de ~/outra — abra lá: jazz -C ~/outra -r <id>.
    • A lista é apagada ao fechar. /resume <id> abre direto.

    Ao abrir, a conversa é desenhada de novo, numa escrita só, sem rodar nada:

    › rode perigoso

● Bash(git branch -D jazz-pty-nada)
  ⎿  BLOCKED: bash `git branch -D jazz-pty-nada` — the user denied it (it is a destr…

● pronto: 300 linhas.

› pergunte algo

● Pergunta(Qual banco usar?)
  ⎿  The user answered: SQLite

● pronto: 300 linhas.

  ✻ conversa anterior · 8 mensagens · 2 ferramentas
  · sessão 261021-170442-e529 retomada (8 mensagens): Rode perigoso

    Cada ferramenta vira uma linha verde ou vermelha a partir do resultado gravado (o texto é o que o modelo recebeu, por isso pode estar em inglês). Só as últimas 200 entradas aparecem, com … (N mais acima, /expand) em cima; /expand mostra o resto (resume_replay: número, all, off).

    Títulos: 5–8 palavras do primeiro pedido, sem chamar modelo. /rename banco de dados do app troca (· sessão 261021-170442-e529: banco de dados do app); /rename sozinho abre o título atual para editar.

    /tree mostra a árvore da sessão na mesma lista:

    › /tree
  árvore da sessão · enter continua dali (novo ramo)
    1 ● você · rode perigoso  23996a59
    2 ● jazz · [bash]  7ae2450c
    3 ● jazz · pronto: 300 linhas.  2f393c77
    4 ● você · pergunte algo  48798e3f
    5 ● jazz · [ask_user]  4f3e2119
  ▸ 6 ● jazz · pronto: 300 linhas.  f80f0742  atual
  6/6  ↑↓ jk move · enter abre · esc cancela · digite filtra

    Enter continua daquela mensagem como um ramo novo, e o ramo é desenhado de novo.

    /rewind volta a conversa (e os arquivos) para antes de uma mensagem sua:

    ╭─ mensagens ───────────────────────────────────────────────────────────────────────╮
│ Voltar para antes de qual mensagem?                                               │
│ filtrar: ▏                                                                        │
│   rode perigoso                                                                   │
│ ▸ pergunte algo                                                                   │
╰───────────────────────────────────────────────────────────────────────────────────╯
  ↑↓ escolhe · digite pra filtrar · enter abre · esc cancela

    10. O que dá pra mudar#

    Config (config.json)VariávelPadrãoEfeito
    mode—(vazio)fixa o modo de início; vazio = turbo com sandbox, senão auto
    trust_default—promptalways confia sem perguntar em pasta sem configuração própria
    always_scope—autosession / project: onde "não perguntar de novo" fica
    session_pickerJAZZ_SESSION_PICKERonoff volta à lista numerada
    resume_replayJAZZ_RESUME_REPLAY200número, all ou off
    ui.paletteJAZZ_PALETTEfuzzyprefix filtra só pelo início do nome
    ui.mention_pickerJAZZ_MENTION_PICKERonoff desliga a lista do @
    ui.history_prefixJAZZ_HISTORY_PREFIXonoff: ↑↓ percorre o histórico todo
    —JAZZ_ASCII=1 / TERM=linux—tudo em ASCII (cima/baixo, 2x)

    Nada disso entra no system prompt: o cache de prompt continua estável entre turnos.
