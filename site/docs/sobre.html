    jazz-cli#

    O jazz é um agente de código para o terminal, escrito em Go: um binário estático só (~11 MB, sem dependências) que lê arquivos, roda comandos num shell persistente, edita código e verifica o que fez, falando com o modelo que você escolher (Anthropic, OpenAI, ChatGPT pela sua conta, OpenRouter, Groq, Gemini, Ollama/llama.cpp e mais uma dúzia de provedores grátis). Ele foi feito para funcionar bem com modelos grátis e fracos e em máquina velha: roda num Mac M-series e também num notebook Pentium M de 32 bits com 2 GB de RAM (um Dell Latitude, linux/386). Para compensar o modelo fraco, o harness cobra o que um prompt só pediria: orçamento de passos, testes rodados de verdade antes de dizer "pronto", guardas contra ação fingida e um sandbox do sistema por baixo de tudo. É um projeto jovem (v0.7), feito por uma pessoa com agentes de IA; espere arestas. Bugs e lacunas conhecidos estão em FINDINGS.md.

    Princípios (detalhes em DESIGN.md):

    • Poucas ferramentas (read, write, edit, bash, todo, fetch, task, script) e um prompt pequeno, que funciona até com modelo grátis e contexto curto.
    • Prompt de sistema e schemas fixos durante a sessão, pra aproveitar o cache de prompt; lembretes vão na mensagem do usuário ou no resultado da ferramenta.
    • Interface leve (editor de linha + ANSI), sem flicker por SSH.
    • Comando perigoso (rm -rf amplo, push --force, curl | sh, sudo…) sempre pede confirmação.

    jazz-cli#

    jazz is a terminal coding agent written in Go: one static binary (~11 MB, no dependencies) that reads files, runs commands in a persistent shell, edits code and checks its own work, talking to the model you choose (Anthropic, OpenAI, ChatGPT through your account, OpenRouter, Groq, Gemini, Ollama/llama.cpp and a dozen free providers). It is built to work well with free, weak models on old hardware: it runs on an M-series Mac and on a 32-bit Pentium M laptop with 2 GB of RAM (a Dell Latitude, linux/386). To make up for a weak model, the harness enforces what a prompt would only ask for: step budgets, tests actually run before "done", guards against faked actions, and an OS sandbox underneath everything. It is a young project (v0.7), built by one person with AI agents; expect rough edges. Known bugs and gaps are in FINDINGS.md. User-facing messages are in Brazilian Portuguese; prompts and code comments are in English.

    Principles (details in DESIGN.md, in Portuguese):

    • Few tools (read, write, edit, bash, todo, fetch, task, script) and a small prompt that works even with a free model and a short context.
    • System prompt and schemas fixed for the session, so the prompt cache keeps working; reminders go into the user message or the tool result.
    • Light UI (line editor + ANSI), no flicker over SSH.
    • Dangerous commands (broad rm -rf, push --force, curl | sh, sudo…) always ask.
