    Documentação do jazz-cli#

    O jazz é um agente de código para o terminal, em Go, num binário estático único. Esta documentação é gerada dos Markdown do repositório; cada página tem um link para a fonte no GitHub. Use a busca (atalho /) para achar um título.

    Comece aqui#

    Quatro passos, na ordem.

    1. Instalar#

    Linux e macOS (o instalador confere a assinatura e o sha256 e instala em ~/.local/bin, sem sudo):

    curl -fsSL https://github.com/jazzautomations/jazz-cli/releases/latest/download/install.sh | sh

    Windows (PowerShell), Termux, Linux 32 bits e compilar do código estão em Instalação.

    2. Primeira execução#

    jazz doctor    # diagnóstico: provedores, shell, sandbox, terminal
jazz           # modo interativo na pasta atual

    Sem chave nenhuma o jazz já funciona, com modelos grátis. Detalhes em Primeiro uso.

    3. Modos de permissão#

    turbo (com sandbox do sistema), auto, plan, ask, smart e yolo. Shift+Tab alterna o modo na sessão. Em repositório desconhecido, use ask. Veja Modos de permissão e a Segurança.

    4. Modelos#

    jazz key openrouter                # salva uma chave (vale pra qualquer provedor)
jazz omni setup                    # liga o roteador entre provedores grátis
jazz -m groq/openai/gpt-oss-120b   # escolhe um modelo

    O omni distribui os pedidos entre os provedores, com os grátis na frente. Em Primeiro uso estão ChatGPT por login, modelos locais e Ollama.

    jazz-cli documentation#

    jazz is a coding agent for the terminal, written in Go, shipped as a single static binary. These pages are generated from the repository's Markdown; each one links to its source on GitHub. Use the search box (shortcut /) to find a heading. Pages without an English version show the Portuguese text with a notice.

    Start here#

    Four steps, in order.

    1. Install#

    Linux and macOS (the installer verifies the signature and sha256 and installs to ~/.local/bin, no sudo):

    curl -fsSL https://github.com/jazzautomations/jazz-cli/releases/latest/download/install.sh | sh

    Windows (PowerShell), Termux, 32-bit Linux and building from source are on the Install page.

    2. First run#

    jazz doctor    # diagnostics: providers, shell, sandbox, terminal
jazz           # interactive mode in the current folder

    jazz works with no key at all, on free models. Details in First run.

    3. Permission modes#

    turbo (with the system sandbox), auto, plan, ask, smart and yolo. Shift+Tab switches the mode inside a session. For an unfamiliar repository, use ask. See Permission modes and Security.

    4. Models#

    jazz key openrouter                # saves a key (works for any provider)
jazz omni setup                    # turns on the router across free providers
jazz -m groq/openai/gpt-oss-120b   # pick a model

    omni spreads requests across providers, free ones first. First run covers ChatGPT login, local models and Ollama.
